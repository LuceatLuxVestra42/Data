시침

★★★★★★

전투 진입 시 공격 방어 +25% 행동 종료 시 하기 스킬을 선택한다. 1) 시간 당기기 : 자신이 보유한 버프, 디버프지속 시간을 추가로 1행동 감소 및 모든 스킬 쿨타임 -1행동 2) 시간 정지 - 자신이 보유한 버프, 디버프 지속 시간이 감소하지 않으며 모든 스킬 쿨 역시 감소하지 않는다. 자신이 위험 범위 안에 있는 상태에서 시간 정지 사용 시, '시간 제어' 효과 획득 시간 제어 : 사망 시 생명 50%로 부활 면역 및 해제 불가 지속 1행동 시간 제어 쿨타임 3행동

전용장비

时序之芒

攻击+10% [趋时]可以使自身所有[触发冷却]额外减少1回合；[凝时]不再拥有冷却时间。自身每有1个技能未处于冷却，部队造成伤害提升5%。

중앙율정

공격 방어 +5% 시간 당기기(턴종료 시 선택 가능, 버프 및 디버프, 모든 스킬의 지속시간 추가로 -1턴)나 시간 정지(턴종료 시 선택 가능, 버프 및 디버프, 모든 스킬 쿨타임의 지속시간 감소 없음, 위험범위 내에서 행동종료 시 50% 체력으로 부활 가능 버프 획득, 1턴 지속)를 사용 후 3칸 재행동 가능(해당 효과의 쿨타임 3턴)

유대
