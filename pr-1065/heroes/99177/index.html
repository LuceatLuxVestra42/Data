고유기

★★★★★★

자신 3칸 범위 안에 아군이 있을 경우 지력 +20% 턴 시작시 자신 주위 2바퀴 범위 안에 지속 1행동의 무작위 지형 효과 '저猪()' '록鹿()' '접蝶()' 효과를 4개 생성한다. 저猪, 록鹿, 접蝶 : 아군이 해당 위치로 이동 후 행동 종료시 무작위 버프 1개 획득하고 카구야는 해당 지형 효과를 얻는다. 저 록 접 효과는 면역 및 해제 불가 [저][록][접] 효과는 최대 3개까지 중첩 가능.

전용장비

浮梦月辉

生命+10% 战斗开始时，随机获得2个[猪][鹿][蝶]。使用[袖中牌]获得的“部队射程+2”效果，无法驱散。本场战斗中，每消耗过任意1个[猪]或[鹿]或[蝶]，英雄暴击率提升1%（最高10%）。

중앙율정

지력 +5% 턴 시작 시, 자신 주위 1바퀴 범위 안에 아군 2명 이상이 있을 경우, 고유기의 화투패(나비, 돼지, 사슴) 장판 생성 범위 카구야 주위 1바퀴로 수축
